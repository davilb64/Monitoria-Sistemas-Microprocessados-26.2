# Monitoria - Laboratório de Sistemas Microprocessados (ENE0440)

Bem-vindos ao repositório de monitoria! 

Esse repositório foi criado para os códigos de exemplo, atividades de revisão e materiais de apoio para as aulas de monitoria da disciplina de Laboratório de Sistemas Microprocessados no semestre 2026.2.

Todos os códigos aqui disponibilizados são para o microcontrolador **MSP430** (especificamente a LaunchPad MSP-EXP430F5529LP) e foram testados na IDE **Code Composer Studio Theia**.

## Estrutura do Repositório

O material está organizado de acordo com os módulos da disciplina:

* **`/Modulo1_Assembly`**: Exercícios de Assembly do MSP430 (modos de endereçamento, saltos, laços, sub-rotinas e passagem de parâmetros usando os registradores).
* **`/Modulo2_Basico`**: Exercícios de GPIO, Timers, Interrupções e PWM.
* **`/Modulo3_Avancado`**: Exercícios de GPIO Comunicação Serial, Conversores A/D e DMA.

## Sobre os Vistos
Os códigos contidos aqui são exemplos de apoio e fixação. Os exercícios que valem ponto (Vistos) devem ser desenvolvidos individualmente (ou em duplas, conforme orientação do professor). Utilizar os códigos de exemplos para basear o seu raciocínio é recomendado, mas lembre-se que o objetivo principal é o seu aprendizado!
