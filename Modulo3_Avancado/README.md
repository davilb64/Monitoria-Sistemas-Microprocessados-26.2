# Módulo 3 - MSP Avançado

Este módulo explora recursos avançados do MSP430.

**Tópicos abordados:**
* **Comunicação Serial:** I2C (Síncrona) e UART (Assíncrona);
* **Conversores A/D:** Leitura de sinais analógicos;
* **DMA:** Acesso Direto à Memória;
* **Display:** Integração com LCD.
